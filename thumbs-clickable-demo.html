✅ How it works:

  • Click any thumbnail to jump to that slide in the main gallery
  • The active thumbnail is highlighted with full opacity and a border
  • Hover over thumbnails to see the interactive effect
Main Slider Configuration:
<div waterfall="gallery-main" waterfall-thumbs="gallery-thumbs" >
Thumbnail Slider Configuration:
<div waterfall="gallery-thumbs" waterfall-slides-per-view="5" waterfall-watch-slides-progress="true" waterfall-free-mode-enabled="true" >

⚠️ Important:

  • DO NOT use waterfall-slide-to-clicked-slide with thumbs - it interferes with clicking
  • Thumbs are NOT clickable by default in Swiper - requires custom click handler
  • waterfall-watch-slides-progress="true" is required on the thumbnail slider
  • waterfall-free-mode-enabled="true" is recommended for better thumb navigation

✅ Controller Module Benefits:

  • Thumbnails ARE clickable when using waterfall-slide-to-clicked-slide="true"
  • Two-way sync: both sliders control each other
  • No custom JavaScript needed
  • Works with waterfall-slide-to-clicked-slide unlike thumbs module
Controller Main Slider (NO controller attr - let it init first):
<div waterfall="controller-main" >
Controller Thumbnail Slider:
<div waterfall="controller-thumbs" waterfall-controller="controller-main" waterfall-slides-per-view="5" waterfall-slide-to-clicked-slide="true" >
