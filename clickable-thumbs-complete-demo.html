Clickable Thumbnails

Two approaches: Thumbs Module vs Controller Module

1. Thumbs Module RECOMMENDED

The thumbs module is designed specifically for thumbnail galleries. Waterfall automatically adds click handlers when you use waterfall-slide-to-clicked-slide="true" on the main slider.

2. Controller Module ALTERNATIVE

The controller module provides two-way synchronization between sliders. Use waterfall-slide-to-clicked-slide="true" on the thumbnail slider to make thumbs clickable.
